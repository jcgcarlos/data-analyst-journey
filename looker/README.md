# Looker / LookML

LookML data models built around **Vela**, a fictional B2B fintech platform.
These files are part of my ongoing data analyst upskilling — practicing
real-world data modeling in Looker using LookML.

---

## Business Context

Vela is a B2B fintech platform that helps businesses manage payments and
financial operations. The models here are designed to help business users
explore transaction performance, user behavior, and revenue trends —
without writing SQL.

---

## Files

| File | Description |
|------|-------------|
| `transactions.view.lkml` | Defines dimensions and measures for the transactions table — including transaction status, amount, and created date |
