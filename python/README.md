## How I Structure Each Notebook

Every `.ipynb` file in this folder follows a four-section format:

**Section 1 — Concept header** (Markdown cell)
What it is for, core syntax, and when to use it. Five lines max.

**Section 2 — Core mechanics** (Code cells)
Stripped-down lesson code. Inline comments only where the *why* isn't obvious.

**Section 3 — Practice exercises** (Markdown + Code cells)
A BI/BA business problem stated in markdown, then my solution in code. This is what makes the notebook portfolio-ready.

**Section 4 — Notes** (Markdown cell)
Three bullets: what clicked, what confused me, what to practice next session.
